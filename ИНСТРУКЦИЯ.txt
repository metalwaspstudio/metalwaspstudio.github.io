  index.html
  metal-wasp-logo.webp

  favicon.png

Как сделать:
1. Откройте https://github.com/metalwaspstudio/metalwaspstudio.github.io
2. Нажмите Add file → Upload files.
3. Перетащите ВСЕ ЧЕТЫРЕ ФАЙЛА из архива (НЕ ZIP).
   GitHub заменит старый index.html, если файл с таким именем уже есть.
4. Внизу нажмите Commit changes и подтвердите сохранение в ветку main.
5. Проверьте https://metalwaspstudio.github.io/ после завершения GitHub Pages Actions.
6. Если браузер показывает прежнее оформление, нажмите Ctrl+F5.
